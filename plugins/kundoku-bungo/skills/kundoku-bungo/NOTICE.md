## Unicode の Unihan データベース

- `references/kanji.tsv` の新字体と旧字体の対応のうち、`kind` が `joyo`・`compat` の行は、Unicode Character Database 18.0.0 の Unihan データベース（`Unihan_Variants.txt` の `kJapaneseOldVariant`）から作った。この項目は、常用漢字表（平成 22 年内閣告示第 2 号）の括弧の中の字体（いわゆる旧字体）に当たる。
- `kind` が `design` の行（衆→眾）は、Unihan からではなく、官報の画像で字の形を確かめて足した。
- Unihan データベースは Unicode License v3 で公開されている。著作権表示と許諾表示を [LICENSE-UNICODE](LICENSE-UNICODE) に置いた。
- 出典: https://www.unicode.org/Public/18.0.0/ucd/Unihan.zip （2026-11-11 に取得）

## 当時の文書での用例（典拠）

`kanji.tsv` の列 `evidence`・`evidence_url` は、その旧字体が明治〜昭和 20 年ごろの公文書で使われていたことの典拠である。

- ウィキソース日本語版の翻刻（`https://ja.wikisource.org/w/index.php?oldid=...`）
  - 日本の政府・官庁の法令・詔勅・告諭などの翻刻で、原典は著作権法 13 条により権利の対象外か、保護期間が満了している。日本以外の政府の文書（満洲国の法令など）は、典拠に使っていない。
  - このスキルには、翻刻の本文を入れていない。字が出てくるページの名前と、版の URL だけを記録した。
  - ウィキソースの編集者が付けた注・現代語訳は使っていない。
- 国立国会図書館デジタルコレクション（`https://dl.ndl.go.jp/pid/...`）
  - 官報の画像（インターネット公開・保護期間満了）で、字の形を確かめた。
  - このスキルには、画像を入れていない。

## 語の表の用例

- `references/vocabulary.tsv` の列 `example` は、ウィキソース日本語版の翻刻から引いた短い一節である。出典は列 `source`・`source_url`（版の URL）にある。
- 引いた原典は、次のどちらかである。
  - 日本の政府・官庁の法令・布告・告諭・訓示など。著作権法 13 条により権利の対象外か、保護期間が満了している。
  - 演説「祝東京專門学校之開校」（小野梓、1882 年）。著作者が 1886 年に亡くなっており、保護期間が満了している。
- 詔書・勅語・勅諭のページと、大日本帝國憲法のページ（天皇の告文・上諭を含む）は、用例に使っていない。天皇の名義でだけ使う言い方を含む一節も、使っていない。
- 列 `reading`（読み）と `meaning`（今の意味）は、このスキルの作成者が書いた。辞書などの説明は写していない。

## 法令の用例

- `references/grammar.md` の条文の用例は、e-Gov 法令検索の「明治十七年太政官布告第三十二号（爆発物取締罰則）」から引用した。法令は著作権法 13 条により権利の対象外である。
- 出典: e-Gov 法令検索（https://laws.e-gov.go.jp/law/117DF1000000032 ）。2026-11-11 に法令 API で取得した。
